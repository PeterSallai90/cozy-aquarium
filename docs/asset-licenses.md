# Asset licenses

Every asset that is not generated by our own scripts gets a row here in the same pull request that
adds it. CI fails if a file in `game/assets/` or an addon in `game/addons/` has no matching row
(`tools/scripts/check_asset_licenses.py`), so assets generated by our own scripts get a row too, with
the generator script as the source and "MIT (this project)" as the license. The File column is the
path relative to `game/`, for example `assets/room/cabinet_01.glb`. Assets under `game/assets/` need
one row per file. An addon (each folder directly in `game/addons/`) needs one row for the whole
folder, for example `addons/gdUnit4/`; a loose file directly in `game/addons/` needs its own row. A
row covers only the exact path it names.
