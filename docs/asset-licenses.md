# Asset licenses

Every asset that is not generated by our own scripts gets a row here in the same pull request that
adds it. CI fails if a file in `game/assets/` has no matching row
(`tools/scripts/check_asset_licenses.py`), so assets generated by our own scripts get a row too, with
the generator script as the source and "MIT (this project)" as the license. The File column is the
path relative to `game/`, for example `assets/room/cabinet_01.glb`.
